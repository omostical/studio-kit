**Status: stable** — covered by Input and Select (helperText, error props).

The text under a field for hints, warnings and error messages. Used inside **Form Field**.

---

**Properties**
- **State** — `Default` · `Error` · `Warning` · `Success`
- **Show/hide** — Icon

---

**Usage guidelines**
- Errors say how to fix the problem ("Enter a date after today").

---

**Accessibility**
- Link it to the field with `aria-describedby`.
