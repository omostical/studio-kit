**Status: planned** — Figma only; there is no code component yet.

Shows a keyboard shortcut (⌘ K) in menus, tooltips and search.

---

**Properties**
- **Emphasis** — `Strong` · `Weak`
- **Symbols** — `1` · `2` · `3` · `4`

---

**Usage guidelines**
- Only show shortcuts that work, and use the right modifier keys for the platform.

---

**Accessibility**
- Expose shortcuts with `aria-keyshortcuts` on the control they trigger.
