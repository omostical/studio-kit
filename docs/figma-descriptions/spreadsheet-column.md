**Status: planned** — Figma only; there is no code component yet.

A column of editable **Spreadsheet Cell** items with a header, for grid-style data editing.

---

**Properties**
- **Type** — `Switch` · `Status Badge` · `Icon` · `Progress` · `Checkbox` · `Tags` · `Text` · `Person` · `Thumbnail` · `Payment Method` · `Empty`
- **Divider** — `False`

---

**Usage guidelines**
- Use for editing many values in place; use **Table** for read-mostly data.

---

**Accessibility**
- Follow the ARIA grid pattern: arrow keys move between cells, Enter edits, Escape cancels.
