**Status: stable** — in code as `Badge`.

A small label that shows the status of an item (Active, Pending, Failed). Use **Tag** for categories and **Chip** for interactive filters.

---

**Properties**
- **Type** — `Label` · `Icon` · `Label + Icon`
- **Status** — `Negative` · `Notice` · `Positive` · `Info` · `Neutral`
- **Emphasis** — `Low` · `High`
- **Shape** — `Square` · `Round`
- **Size** — `Small` · `Medium` · `Large`
- **Text** — Text

---

**Usage guidelines**
- Use a small, consistent set of statuses across the product.
- Pick the colour by meaning (positive, notice, negative, info, neutral).

---

**Accessibility**
- Status must be readable as text; never use colour or the icon alone.
