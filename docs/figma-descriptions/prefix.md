**Status: stable** — covered by Input and Select (prefix prop).

Content at the start of a field (icon, text, country code, small button). Used inside Input, Search and Select.

---

**Properties**
- **Type** — `Text` · `Button` · `Avatar` · `Icon`
- **Contained** — `True` · `False`
- **🚫 Size** — `Small` · `Medium` · `Large`
- **Text** — Prefix

---

**Accessibility**
- Text prefixes ("$", "https://") should be part of the field's accessible name or description.
