A button that opens a filter and shows whether it's active, for table and list toolbars.

---

**Properties**
- **Size** — `Medium` · `Small` · `Large`
- **State** — `Default` · `Hover` · `Pressed` · `Disabled` · `Active`
- **Selected** — `False` · `True`
- **Show/hide** — Prefix
- **Text** — Value

---

**Usage guidelines**
- Show the active value or count in the button ("Status: Open", "Filters · 2").
- Offer a quick way to clear filters.

---

**Accessibility**
- Include the active state in the accessible name, and use `aria-expanded` when it opens a popover.
