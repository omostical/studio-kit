A field for attaching files, combining a **Dropzone** with the list of uploaded **File** items.

---

**Properties**
- **Type** — `Button` · `Dropzone`
- **Show/hide** — Files

---

**Usage guidelines**
- State accepted file types and size limit before people choose a file.
- Show progress and allow cancelling or removing each file.

---

**Accessibility**
- Keep a real file input (or a button that opens it) so the field works without drag and drop.
- Announce upload progress and errors in text.
