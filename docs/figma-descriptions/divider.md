A thin line that separates groups of content, optionally with a label. Use spacing first; add a divider only when spacing isn't enough.

---

**Properties**
- **Style** — `Solid` · `Dashed`
- **Weight** — `Thin` · `Default` · `Bold`
- **Emphasis** — `Base` · `Strong` · `Subtle`
- **Text** — `Center` · `Left` · `None`

---

**Usage guidelines**
- Don't use dividers between every item in a list or between a heading and its content.

---

**Accessibility**
- Decorative dividers need no role; use `<hr>` or `role="separator"` only for a real thematic break.
