A large clickable tile that starts an action or goes somewhere ("Create project", "Import data").

---

**Properties**
- **Style** — `Border` · `Filled`
- **State** — `Default` · `Hover` · `Pressed` · `Focused` · `Disabled`
- **Show/hide** — Description, Entity, Icon Button
- **Text** — Description Text

---

**Usage guidelines**
- Use for a small set of starting points, not as general navigation.

---

**Accessibility**
- Make the tile one link or button with a clear name; don't nest other controls inside.
