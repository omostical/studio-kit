**Status: beta** — in code as `Table`.

One cell of a table: text, number, badge, avatar, actions and other content types.

---

**Properties**
- **Type** — `Empty` · `Header →` · `← Header` · `Text` · `Checkbox` · `Status Badge` · `Tags` · `Text Input` · `Select` · `Switch` · `Progress` · `Button` · `Icon` · `Person` · `Thumbnail` · `Number` · `Payment Method`
- **Size** — `Small` · `Medium` · `Large`
- **State** — `Default` · `Hover` · `Pressed`
- **Selected** — `False` · `True`
- **Flushed Margins** — `False` · `True`
- **Show/hide** — Description, Sorting

---

**Usage guidelines**
- Keep one kind of content per column and truncate long text with a tooltip.

---

**Accessibility**
- Row actions need labels that include the row ("Edit Adam Smith").
