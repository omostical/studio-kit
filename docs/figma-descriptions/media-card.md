**Status: planned** — Figma only; there is no code component yet.

A card led by an image or video (articles, templates, products). Pick the Ratio that matches the media. Use **Default Card** when there's no image.

---

**Properties**
- **Ratio** — `16:9` · `1:1` · `21:9`
- **Container** — `True` · `False`
- **Show/hide** — Header, Description

---

**Usage guidelines**
- Crop images to the chosen ratio; don't stretch them.
- Keep the title short and put one clear action in the card.

---

**Accessibility**
- Give informative images alt text; mark purely decorative images `alt=""`.
- Follow Default Card guidance for headings and clickable cards.
