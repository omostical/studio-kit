**Status: planned** — Figma only; there is no code component yet.

A floating bar of actions that appears when people select items (rows in a table, files, cards) and applies the actions to that selection.

---

**Properties**
- **Type** — `Default`
- **Show/hide** — More Actions

---

**Usage guidelines**
- Show the number of selected items and a way to clear the selection.
- Keep 2–5 actions; put the rest in a "More" menu.
- Hide it as soon as nothing is selected.

---

**Accessibility**
- Announce selection changes with a polite live region ("3 items selected").
- Make sure keyboard users can move focus to the bar after selecting.
